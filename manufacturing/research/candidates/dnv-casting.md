# dnv casting

status: drafted

## finding

dnv casting (brooklyn, us) casts 10k, 14k, 18k gold, platinum and silver, uses
industrial-grade 3d printers for castable patterns, offers cad modeling/design,
and advertises next-day turnaround for print and cast orders. inquiries accept
stl and 3dm design uploads.

## conditions and caveats

- no public api evidence; automation is upload-form level. adapter would need
  custom integration or manual-quote mode.
- next-day turnaround claim needs production confirmation against real order
  volumes.

## sources

- [dnv casting homepage](https://dnvcasting.com/): metal list, 3d printing, next-day turnaround, brooklyn studio, stl/3dm upload. (retrieved 2026-10-12)
