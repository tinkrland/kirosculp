# evidence log

every external claim gets a row in offerings/research/sources.md.

## steps

1. add a dated subsection heading: ### <topic> (<date>)
2. add a table row per source: | source | what it actually supports | boundary |
3. the boundary column must state the limitation honestly
   (dealer guide, marketplace listing, vendor docs, single source).
4. if a claim cannot be sourced, do not write it into specs; record it
   as open question instead.
5. claims already logged in audit/security.md do not need duplicate rows.

## example row

| lang university art deco page | cubist reading of deco geometry | dealer education content; motif families held out of scope |
