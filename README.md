# agent-instructions

orphan branch holding kiro.dev working materials (steering docs and
skills) for the sculptura repository, kept out of the main tree.
no shared history with main; main holds the product.

- `steering/` — product, architecture, and conventions steering for
  kiro agent sessions
- `skills/` — leg-spec and evidence-log skills used to drive
  spec-to-code legs

the main repository lives on `main` (tinkrland/sculptura). checkout
this branch into a kiro.dev workspace when running agent sessions;
work product merges back to main as normal commits, never by merging
this branch.
