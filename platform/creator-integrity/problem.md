# problem: autonomous creator-account farming

sculptura creator profiles represent people. tessa is built into the studio,
so the problem is not whether a creator uses ai.

the abuse case is an autonomous agent acting as the creator: dumping scraped
pinterest references into the studio, generating releases and mass-publishing
listings for dropshipping without accountable human direction.

this can flood discovery with repetitive products, exploit free studio
allowances and create copyright, moderation and customer-support risks.
paracraft validation does not resolve it: manufacturability establishes
physical validity, not accountable authorship or responsible account operation.

## boundaries

- do not classify work as abusive because tessa helped create it.
- do not equate output volume, aesthetics or inexperience with automation.
- distinguish human-operated sales automation from an autonomous creator identity.
- creator admission is not payout kyc. sculptura does not collect or verify
  government-id documents itself; provider-handled payout verification is separate.
- storefront publication requires a phone number on file and verified email.
  those are contact requirements, not proof of personhood or legal identity.
